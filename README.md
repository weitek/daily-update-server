# Daily Update Server

Скрипт для ежедневного автоматического обновления сервера: системных пакетов, Homebrew, npm, Docker-контейнеров Multica, а также очистки неиспользуемых Docker-образов и опциональной перезагрузки.

## Состав

- `update-server.sh` — основной скрипт обновления
- `install.sh` — установка скрипта и systemd-таймера
- `update-server.service` — systemd unit для запуска
- `update-server.timer` — systemd timer для ежедневного запуска

## Установка

```bash
sudo ./install.sh
```

Таймер запускает обновление ежедневно в 03:00. При необходимости перезагрузки сервер перезагружается через 1 минуту после завершения обновления.

## Логи

Все действия логируются в `/var/log/update-server.log`.
